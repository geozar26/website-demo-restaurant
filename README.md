Kitchen Grid – Restaurant Website

Kitchen Grid is a responsive restaurant website built to showcase menu items, featured dishes, customer reviews, and restaurant information through a modern and interactive interface.

---

## Features

- Featured dishes carousel
- Food gallery with image preview
- Dish search by name or ingredients
- Daily specials section
- Customer testimonials
- Responsive navigation menu
- Mobile-friendly layout
- Dish modal popups with descriptions
- Login interface UI

---

## Built With

- HTML5
- CSS3
- JavaScript
- TypeScript-based structure

---

## Responsive Design

The website is optimized for:

- Mobile devices
- Tablets
- Desktop screens

---

## Project Structure

/images
/style.css
/script.js
/index.html

---

No installation or backend configuration is required.

---

 ## Project Purpose

This project was created to practice front-end development, responsive layouts, UI interactions, and restaurant website design.

---



This project is front-end only and does not include a backend or real ordering system.
